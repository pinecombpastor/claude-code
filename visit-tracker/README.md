# Visit Tracker

Single-file browser tool for logging pastoral visits and seeing who is due for one.

## Use

Open `index.html` in any browser. No install or server needed.

- Log a name, date, and short note.
- The list shows each person's most recent visit, oldest first.
- Anyone past the "Flag after N days" threshold (default 30) shows in red.
- ✕ removes a person and all their visits.

## Privacy

Data is saved in your browser's `localStorage` only. It never leaves your device, and it is not shared between browsers or devices. Clearing site data erases it. Keep notes non-sensitive.
